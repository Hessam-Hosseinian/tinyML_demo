# ImageClassifier

یک اپلیکیشن اندرویدی برای دسته‌بندی تصویر به‌صورت آفلاین و روی خود دستگاه. این پروژه با هدف نمایش کاربرد TinyML و TensorFlow Lite در پردازش تصویر پیاده‌سازی شده و می‌تواند تصویر انتخاب‌شده از گالری یا دوربین را با مدل MobileNet طبقه‌بندی کند.

## قابلیت‌ها

- انتخاب تصویر از گالری
- گرفتن عکس با دوربین
- اجرای مدل به‌صورت On-device و بدون نیاز به اینترنت
- نمایش سه نتیجه برتر همراه با درصد اطمینان
- نمایش زمان اجرای inference

## تکنولوژی‌ها

- Kotlin
- Jetpack Compose
- TensorFlow Lite Task Vision
- MobileNet Quantized Model
- Gradle Kotlin DSL

## اجرای پروژه

1. پروژه را با Android Studio باز کنید.
2. Gradle Sync را اجرا کنید.
3. برنامه را روی Emulator یا دستگاه اندرویدی اجرا کنید.

حداقل نسخه اندروید موردنیاز: `Android 7.0` یا `API 24`

## اعضای پروژه

- حسام حسینیان
- آرین خیراندیش

## توضیح کوتاه

این پروژه نشان می‌دهد که چگونه می‌توان یک مدل یادگیری ماشین سبک را داخل اپلیکیشن اندرویدی قرار داد و بدون ارسال داده به سرور، تصویر را مستقیماً روی دستگاه تحلیل کرد. این ویژگی باعث کاهش تأخیر، افزایش حریم خصوصی و امکان استفاده آفلاین از برنامه می‌شود.
